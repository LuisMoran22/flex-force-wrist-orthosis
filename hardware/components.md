# Hardware Components

## Core Electronics

- Arduino Nano
- Sensor Flex 25K
- MPU6050 accelerometer/gyroscope module
- OLED 128x64 display
- Buttons
- Resistors
- General electronic components

## Orthosis and Mechanical Materials

- Neoprene fabric
- ABS filament
- 3D-printed support base
- Copper board
- Ferric chloride

## Functional Purpose

The hardware was selected to support a wearable rehabilitation orthosis capable of collecting force/movement-related measurements, wrist angle information, and EMG activity from forearm muscles.
